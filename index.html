УСТАНОВКА НА IPHONE

Добавь NMT English на экран «Домой»

  1. Открой сайт в Safari на iPhone.
  2. Нажми кнопку «Поделиться».
  3. Выбери «На экран Домой».
  4. Подтверди добавление.

Для офлайн-режима сначала открой приложение при подключённом интернете и дождись загрузки. Затем оно сможет открываться без сети.
