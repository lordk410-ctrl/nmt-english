# NMT English PWA: установка только через iPhone

Это PWA: сайт, который можно добавить на экран «Домой» и запускать в отдельном окне. Mac и App Store для этого варианта не нужны.

## Что включено
- 20 заданий на календарный день.
- Подборка фиксируется на день и не меняется при перезапуске.
- Проверка ответа и краткое объяснение.
- Общая статистика и точность по темам.
- Локальное сохранение в браузере на устройстве.
- Service Worker для кеширования приложения и базового офлайн-запуска.
- Адаптивный интерфейс в строгом академическом стиле.

## Важно про ежедневные уведомления
PWA-проект не включает автоматические ежедневные уведомления. На iPhone веб-push уведомления требуют установки на экран «Домой», iOS 16.4 или новее, явного разрешения пользователя и работающего push-сервера. В этой версии можно пользоваться напоминанием в приложении «Напоминания» iPhone. Автоматическую push-инфраструктуру можно добавить отдельным этапом.

## Самый простой способ опубликовать проект с iPhone: GitHub Pages
Публикация требует HTTPS, а GitHub Pages его предоставляет.

### Шаг 1. Создай репозиторий
1. Открой Safari и перейди на https://github.com
2. Войди или создай аккаунт.
3. Нажми `+` → `New repository`.
4. Назови репозиторий `nmt-english`.
5. Выбери `Public`, затем `Create repository`.

### Шаг 2. Загрузи файлы
1. Распакуй ZIP на iPhone через приложение «Файлы» (тапни по ZIP).
2. В репозитории GitHub нажми `Add file` → `Upload files`.
3. Загрузи `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `service-worker.js`, `README_RU.md` и папку `icons`.
4. Если мобильный интерфейс не показывает загрузку папки, создай папку `icons` через `Add file` → `Create new file`, введи `icons/.keep`, затем загрузи два PNG в папку `icons`.
5. Нажми `Commit changes`.

### Шаг 3. Включи GitHub Pages
1. Открой `Settings` репозитория.
2. Выбери `Pages`.
3. В разделе `Build and deployment` выбери `Deploy from a branch`.
4. Branch: `main`, folder: `/ (root)`.
5. Нажми `Save`.
6. Подожди минуту или две. Адрес будет вида `https://ТВОЙ-ЛОГИН.github.io/nmt-english/`.

### Шаг 4. Установи на iPhone
1. Открой опубликованный адрес именно в Safari.
2. Дождись полной загрузки приложения при интернете.
3. Нажми «Поделиться» в Safari.
4. Выбери «На экран Домой» → «Добавить».
5. Запускай NMT English с новой иконки на домашнем экране.

### Шаг 5. Проверь офлайн-режим
1. Сначала открой приложение онлайн и подожди, пока загрузятся файлы.
2. Закрой его.
3. Включи авиарежим.
4. Запусти приложение с иконки. Основной интерфейс, задания и статистика должны работать без интернета.

## Обновление вопросов или дизайна
Измени нужный файл в GitHub через `Edit` или загрузи новую версию. После публикации обновления открой приложение с интернетом. Если старая версия остаётся в кеше, закрой PWA полностью и открой снова; иногда помогает перезагрузка Safari.

## Данные и приватность
Результаты сохраняются в localStorage на конкретном устройстве и в конкретном браузерном контексте. Очистка данных сайта или удаление сайта может удалить прогресс. Пока нет синхронизации между устройствами и резервного копирования.

## Ограничения текущей версии
- Встроено 31 авторское тренировочное задание. Это демонстрационный банк, а не полный банк НМТ.
- Из него ежедневно выбираются 20 заданий. Банк следует расширить и вычитать с преподавателем.
- Уведомления не планируются автоматически самим PWA.
- Приложение не опубликовано в App Store: это устанавливаемое веб-приложение.


## База из 1000 вопросов
Файл `questions.js` содержит 1000 авторских тренировочных вопросов. Он подключается перед `app.js`. Для обновления на GitHub замените `app.js`, `index.html`, `service-worker.js` и добавьте `questions.js` в корень репозитория. Вопросы не являются официальными заданиями УЦОЯО.
